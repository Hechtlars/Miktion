# Miktion – Version 2.7

Erweitert nach dem Toiletten-/Trinkprotokoll der Deutschen Kontinenz Gesellschaft:
- bestehende Erfassung orientiert sich weiterhin an Trinkmenge, Harnmenge, Harndrang, Urinverlust und Vorlagenwechsel
- neuer Kontinenz-Fragebogen in 4 Schritten mit den Antwortmöglichkeiten der Vorlage
- Mehrfachauswahl bei „Wann kommt es zu Urinverlust?“
- Antworten werden lokal gespeichert und können geändert werden
- ausgefüllter Fragebogen wird in den Arztbericht aufgenommen
- neuer Informationsbereich „Hauptursachen & Tipps“
- Belastungsinkontinenz und Harndranginkontinenz werden patientengerecht erklärt
- Alltagstipps aus der Vorlage mit medizinischem Hinweis, dass sie keine individuelle Therapieempfehlung darstellen
- beim vollständigen Zurücksetzen des Tagebuchs wird auch der Fragebogen zurückgesetzt
- Startseite bleibt konsequent auf Datenerfassung fokussiert
